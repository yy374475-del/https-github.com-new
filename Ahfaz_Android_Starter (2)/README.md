# أحفظ (Ahfaz)

تطبيق أندرويد لتجميع الدروس ومراجعتها والتسميع الصوتي.

## الميزات
- إضافة الدروس يدويًا وحفظها على الجهاز.
- اختيار صورة واستخراج النص منها باستخدام ML Kit.
- وضع دراسة يعرض النص ويتيح قراءته بصوت Android Text-to-Speech.
- تسميع صوتي عبر خدمة التعرف على الكلام المتوفرة على الجهاز، مع مقارنة تقريبية للنص.
- بناء APK تلقائيًا عبر GitHub Actions.

## تنبيه حول OCR
إعداد ML Kit الافتراضي المضمّن هنا مخصص للنصوص اللاتينية، وليس OCR العربي. يمكن إدخال النص العربي يدويًا، أو ترقية OCR لاحقًا إلى حل يدعم العربية. راجع النص المستخرج دائمًا قبل حفظه.

## بناء APK
افتح تبويب Actions وشغّل workflow المسمى Build Ahfaz APK. بعد نجاحه، نزّل artifact باسم Ahfaz-APK، وفك ضغط ZIP للعثور على APK.
